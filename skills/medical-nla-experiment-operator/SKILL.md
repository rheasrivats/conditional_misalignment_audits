# Legacy Medical NLA Evidence Overlay

Use this overlay only for historical medical-project evidence. Do not use it as
the primary workflow for new NLA experiments.

1. Read `skills/nla-experiment-operator/SKILL.md` and its task-specific
   reference first.
2. Read [references/project-artifacts.md](references/project-artifacts.md) when
   resolving the completed medical baseline's paths, counts, snapshots,
   decisions, incidents, or revealed-review artifacts.
3. Read the relevant historical lesson when it affects compatibility or
   interpretation:
   - [references/runtime-and-recovery.md](references/runtime-and-recovery.md);
   - [references/fidelity-development.md](references/fidelity-development.md);
   - [references/activation-probes.md](references/activation-probes.md);
   - [references/judging-and-interpretation.md](references/judging-and-interpretation.md).
4. Recheck current repository, provider, stage, ledger, and decision state.
   Historical paths and statuses in this overlay may have successors.
5. Treat every medical setting, version, count, threshold, repair, and result
   as historical evidence, never a default for a new domain or run.
6. Preserve append-only decisions and incidents. Do not rename historical run
   paths or rewrite frozen artifact references merely because the generic skill
   now governs current work.

When handing off legacy medical work, identify the generic governing workflow,
the exact medical evidence loaded from this overlay, and any limitation on
transferring that evidence to a non-medical project.
